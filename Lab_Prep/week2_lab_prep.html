You're ready for lab

Lab 2A uses these same commands on a dataset from Project STAR, a randomized experiment on class size in Tennessee schools. The syntax will be identical. What changes is the data and the questions.

One thing to carry with you. Every command here answered a small mechanical question, but each one also raised a bigger one: is the mean a fair summary, does a cutoff we chose ourselves change the answer, can we call a gap between two groups an effect. Those are the questions lab is for.

Commands covered
  • data()  load a built-in dataset
  • View()  open the spreadsheet viewer
  • head()  first six rows
  • dim()  rows and columns
  • names()  variable names
  • sum(is.na())  count missing values
  • mean()  average, with na.rm
  • hist()  distribution of one variable
  • summary()  all variables at once
  • table()  counts by category
